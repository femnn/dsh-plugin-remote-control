# 远程操控 · Remote control

DSH 右侧栏的**安卓手机 / 电视远程操控台**：自动连接、实时画面与点按、AI 看图操控、投屏、发文件装 APK，并附带一套给 Agent 的操控工具。

> DeepSeek Harness 插件 · 同一个包提供 Host 半片（`/api/phone-remote` 的 ADB 路由）和浏览器半片（右侧栏标签页）。

## 亮点

- **不用填 IP**：mDNS 自动发现手机的无线调试端口和电视的 ADB 广播，连上后按机型记住名字，设备换 IP 也能找回。
- **AI 看图操控**：把任务说给大模型，它会**真的看屏幕截图**再决定下一步（点哪里 / 输入什么 / 按什么键），执行完再看结果，能自己纠错重试——不是关键词盲翻译。
- **实时画面可交互**：低分辨率屏幕流（约 10 fps），点画面即点手机。
- **手机电视通吃**：同一套操控板，电视用方向键，手机用触屏。
- **投屏两向**：电脑画面 → 手机/电视；设备 A 的画面 → 设备 B。
- **不残留**：串流和重装都会自动回收采集进程并恢复设备亮屏设置，不会把设备编码器占死、也不会让手机一直自己亮。

## 安装

在 DSH 的 **插件（Plugins）** 里安装本地目录，或用 `plugin_manager`：

```
install_bundle → target = <本目录绝对路径>
```

依赖本机 `adb`（自动探测）和 `ffmpeg`（自动探测；实时画面与投屏需要）。可在插件配置里指定 `adbPath` / `ffmpegPath` / `downloadDir`。

设备端要求：已开启「无线调试」并授权这台电脑；电视需开启 ADB 广播。

## 用法

**面板**：右侧栏「远程操控」标签页。左侧选设备，中间是实时画面，右侧是操控板；「所有设备」里是设备卡片网格和群聊。

**AI 操控**：在「用 AI 操控」框里说一句（如「打开B站搜周杰伦」），模型会一步步看屏操作，面板会显示它「看到什么 → 做了什么」。

**Agent 工具**：`phone_devices`、`phone_apps`、`phone_launch`、`phone_command`、`phone_cast` 等。
