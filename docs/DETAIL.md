# 远程操控（Remote control）

在 DSH 的**右侧栏**开一个安卓设备远程操控台——手机和电视都能用——并给 Agent 一套直接操控设备的工具。

## 面板能做什么

- **自动发现连接**：用 mDNS 找手机（`_adb-tls-connect._tcp`）和电视（`_adb._tcp`），连上后按**机型**记住名字，设备换 IP 也认得出来；不用手填 IP。
- **实时画面**：低分辨率（约 640 长边）屏幕流，桌面端解码成 MJPEG 推给面板，操作时约 10 fps；画面静止时自动用快速截图兜底。
- **点画面即点手机**：点实时画面直接点按对应位置（按设备真实宽高比换算像素坐标）。
- **系统按键**：返回 / 主页 / 多任务 / 电源 / 音量±。
- **输入文字**：往当前焦点输入框打字。
- **AI 看图操控**：用一句话描述任务，**多模态模型会真的看屏幕截图**再决定下一步——点哪里、输入什么、按什么键——执行完再截图看结果，能自己纠错重试。
- **投屏**：把电脑画面推到手机或电视（电脑采集 → MJPEG → 设备用浏览器打开）。
- **设备间转串流**：把 A 的画面转到 B 上显示。
- **发文件 / 装 APK**：把本地文件推到设备，或安装 APK。
- **所有设备**：设备卡片网格（画面预览 + 在线状态 + 电量）+ 群聊，可在群聊里 `@设备` 指挥多台设备。

## 给 Agent 的工具

`phone_devices`、`phone_apps`、`phone_launch`、`phone_command`、`phone_cast`、`phone_connect` 等：Agent 可以查设备、启动 App、执行中文指令（`打开B站`、`向右`、`确认`、`输入：周杰伦`）、投屏。

## 说明与限制

- 依赖本机 `adb`（自动探测，或在插件配置里指定 `adbPath`）；实时画面与投屏还需要 `ffmpeg`（自动探测或配置 `ffmpegPath`）。
- 设备需已授权这台电脑的 ADB 调试；首次连接需在设备上确认。
- 无线调试端口每次重启可能变化，插件会通过 mDNS 自动找回。
- 实时画面与投屏属于「把画面送到本机再转发」，延迟取决于 WiFi；比原生 scrcpy 略高，但无需额外安装。
- 串流期间设备会被临时设为常亮以避免录到黑屏，**断开后会自动恢复**。
- 所有 ADB 调用在本机 Host 完成；面板只调用同源 `/api/phone-remote/*`。
